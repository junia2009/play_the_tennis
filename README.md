# Play the Tennis

スマホのブラウザで遊べる 3D テニスゲーム（Three.js）。CPU と 1 セットマッチで対戦します。

## 遊び方

- **移動**: 画面左側をドラッグ（フローティングスティック）／ 矢印キー・WASD
- **打つ**: ボールが来たらショットボタンで「予約」→ 届く位置に来ると自動でスイング。早く押すほど強い球
- **狙う**: 打つ瞬間のスティックの向き（上＝深く、下＝浅く、左右＝コース）
- **サーブ**: ボタンでトス → もう一度押して打つ（最高点付近で打つと良いサーブ）
- **移動補助**: スティックを離していると打点へ自動で寄る（設定で OFF 可）

| ショット | ボタン | キー |
| --- | --- | --- |
| フラット | 青 | J / Space |
| トップスピン | 緑 | K |
| スライス | 橙 | L |
| ロブ | 紫 | I |

## 構成

```
index.html          画面・スタイル
js/config.js        定数（コート寸法・ショット性能・難易度）
js/physics.js       ボール物理・ショット計算・軌道予測
js/score.js         スコア計算（デュース・タイブレーク）
js/match.js         試合進行・ルール判定・CPU AI・移動補助
js/input.js         タッチ / キーボード入力
js/ui.js            タイトル・設定・スコアボード・結果画面
js/audio.js         WebAudio による効果音
js/render/          three.js による描画（シーン・キャラクター）
sw.js               オフライン用 Service Worker
```

ゲームロジック（config / physics / score / match）は three.js に依存しないので Node でテストできます。

```
npm test
```

ローカルで動かす場合は任意の静的サーバーで配信してください（例: `python3 -m http.server`）。
